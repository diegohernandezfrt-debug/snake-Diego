# 🐍 Snake - Godot 4.2.2

Videojuego clásico Snake desarrollado en **Godot Engine 4.2.2** usando **GDScript**.

## 🎮 Características
- Movimiento fluido en 4 direcciones
- Sistema de colisiones
- Diferentes tipos de comida con efectos
- Sistema de puntaje
- Reinicio de partida

## 🛠️ Tecnologías
- Motor: Godot Engine 4.2.2
- Lenguaje: GDScript
- Plataforma: PC (Windows)

## 🧩 Controles
- **W / A / S / D** o **Flechas**
- Botón **Restart** para reiniciar la partida
